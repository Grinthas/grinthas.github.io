# Windows Lite: чистая Windows 10 для слабых ПК

Скрипты собирают облегчённую Windows 10 из **официального** образа Microsoft
(готовый ISO здесь не выкладывается: распространять изменённую Windows запрещает лицензия).
Скрипты работают только под Windows. Windows 11 они тоже поддерживают.

> **Важно про обновления безопасности.** Поддержка Windows 10 закончилась 14 октября 2025 года,
> а бесплатные расширенные обновления (ESU) для домашних пользователей — 13 октября 2026 года.
> Новых исправлений уязвимостей Windows 10 Home/Pro больше не получает.
> Защитник Windows продолжает обновлять антивирусные базы, но для ПК, на котором вводятся пароли
> и банковские данные, безопаснее Windows 11 (эти же скрипты соберут её и для «неподходящего» железа).

## Что получится

- одна редакция (Home или Pro), образ заметно меньше оригинального;
- нет предустановленного мусора: Кортаны, Candy Crush и других игр, Paint 3D, Print 3D,
  «Новостей и интересов», погоды, Skype, Портала смешанной реальности, Xbox Game Bar,
  «Советов», пасьянсов, OneDrive и т. п.;
- на панели задач только значок поиска, без Кортаны, «Людей», Meet Now и ленты новостей;
- отключены реклама в меню «Пуск», «рекомендуемые» приложения и телеметрия
  (на Home полностью телеметрию Microsoft отключить не даёт, остаётся минимум);
- локальная учётная запись без интернета и аккаунта Microsoft;
- не резервируются ~7 ГБ диска под обновления.

**Не трогается:** Защитник Windows, Центр обновления, Microsoft Store, драйверы,
калькулятор, блокнот, фотографии, терминал. Система остаётся безопасной и обновляемой;
любое удалённое приложение можно вернуть из Microsoft Store.

## 1. Собрать ISO

1. Скачайте официальный ISO Windows 10 (22H2, 64 бит) с сайта Microsoft:
   [microsoft.com/ru-ru/software-download/windows10](https://www.microsoft.com/ru-ru/software-download/windows10).
   Если на странице только Media Creation Tool — запустите его и выберите «Создать установочный носитель» →
   «ISO-файл». Такой ISO содержит `install.esd`, скрипт это понимает.
2. Скачайте эту папку (`windows-lite`) на компьютер с Windows.
3. Запустите **`build.cmd`**, подтвердите запрос администратора, укажите путь к ISO и номер редакции.
4. Подождите 30–60 минут. Рядом со скриптом появится `Windows-Lite.iso`.

Нужно ~25 ГБ свободного места на диске C:. Можно запускать и из PowerShell:

```powershell
powershell -ExecutionPolicy Bypass -File .\build-lite-iso.ps1 -IsoPath D:\Win10_22H2_Russian_x64.iso -Index 6
```

## 2. Установить

Запишите `Windows-Lite.iso` на флешку через [Rufus](https://rufus.ie)
(схема разделов GPT для UEFI или MBR для старых ПК с BIOS), загрузитесь с неё и установите
как обычно. На экране входа в аккаунт сразу будет создание локального пользователя.

## 3. Оптимизировать

После установки (или на уже установленной обычной Windows) запустите **`optimize.cmd`**:

- создаёт точку восстановления, чтобы всё можно было откатить;
- удаляет те же лишние приложения и OneDrive;
- отключает телеметрию, рекламу, фоновые приложения, Game Bar и запись игр;
- ставит визуальные эффекты на быстродействие (шрифты остаются сглаженными);
- на ПК включает схему питания «Высокая производительность» (на ноутбуке не трогает);
- отключает гибернацию — освобождает на диске место, равное объёму ОЗУ;
- на SSD отключает SysMain, на жёстком диске оставляет (там он ускоряет запуск программ);
- чистит временные файлы.

Если диск совсем медленный, можно отключить индексирование поиска:

```powershell
powershell -ExecutionPolicy Bypass -File .\optimize.ps1 -NoIndexing
```

## Советы для слабого ПК

- Самое заметное ускорение даёт **SSD** вместо жёсткого диска — даже самый дешёвый.
- Windows 10 нормально работает от 4 ГБ ОЗУ; на 2 ГБ запустится, но браузер и игры будут тормозить.
- Для Minecraft на 4 ГБ ОЗУ: выделяйте игре не больше 2 ГБ и ставьте Sodium / Embeddium.
- Уберите лишнее из автозагрузки: Диспетчер задач → Автозагрузка.
